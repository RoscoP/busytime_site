Status Colors

BusyTime shows your calendar status as a color. The colors below apply to the BusyTime Pyramid and Matrix. Third-party displays receive the same colors.

ColorStateMeaning
FreeNo busy events.
Free, scheduledScheduled event that is marked free (for example, all-day events).
UpcomingA busy time is coming up.
Busy, more to followCurrently busy, and another busy time follows.
BusyCurrently busy.
ErrorThe device cannot read the calendar. The light pulses between blue and red.
OffNo upcoming busy times, or outside the checking hours.

If the light shows the error pattern, see Troubleshooting.
